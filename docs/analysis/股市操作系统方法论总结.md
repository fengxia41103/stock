## 概览：7套方法论体系

本文整理了7套经过验证的股市操作方法论，覆盖**长线投资→中线波段→短线日内**全频谱，按适用场景分层：

| 层级 | 方法论 | 作者/出处 | 适用周期 | 核心理念 |
|------|--------|----------|---------|---------|
| 长线 | 达尔文投资法 | Pulak Prasad | 年-十年 | 排除烂公司→买优质→极度懒惰 |
| 长线 | 价值投资 | Benjamin Graham | 年-十年 | 安全边际→低估买入→价值回归卖出 |
| 中线 | SEC财报健康分析 | 综合框架 | 季-年 | 5报表健检→红旗识别→量化打分 |
| 短线 | 箱体操作 | 综合框架 | 天-周 | RSI+箱体+止损纪律 |
| 日内 | 日内交易系统 | Andrew Aziz | 分钟-天 | VWAP+形态+风控 |
| 日内 | One Good Trade | Mike Bellafiore | 分钟-天 | Playbook+复盘+纪律 |
| 心理 | 交易心理学 | Mark Douglas | 全周期 | 概率思维+接受风险+进入Zone |

## 一、达尔文投资法（长线核心）

**出处**：Pulak Prasad,《What I Learned About Investing from Darwin》, Columbia Business School Publishing, 2023

**作者背景**：Nalanda Capital创始人/CEO，管理~$50亿AUM，专注印度上市公司

### 核心流程

```
[1] Kill List排除（10条）→ 触犯任何一条？→ 放弃
[2] ROCE持续>15%？(5年以上) → 否？→ 放弃
[3] 护城河来源清晰且可持续？ → 不确定？→ 放弃
[4] 管理层诚信+能力？ → 有疑问？→ 放弃
[5] 估值合理？ → 太贵？→ 加入观察清单
[6] 买入，然后极度懒惰
```

### Kill List（10条排除标准）

| # | 标准 | 逻辑 |
|---|------|------|
| 1 | 管理层不诚信 | 骗过一次必骗第二次 |
| 2 | 高杠杆 | 放大下行，衰退中致命 |
| 3 | 连续并购型 | 绝大多数并购毁灭价值 |
| 4 | 行业变化过快 | 今天的赢家是明天的输家 |
| 5 | 困境反转型 | 困境中的公司大多继续困境 |
| 6 | 利益不一致 | 大股东/管理层 vs 小股东 |
| 7 | 国企 | 非市场化决策 |
| 8 | 单一客户/产品依赖 | 集中度风险 |
| 9 | 模式复杂难懂 | 不懂就无法评估 |
| 10 | 欺诈/操纵历史 | 文化不会改变 |

### 三大支柱

1. **避免大风险** — 亏50%需要赚100%才能回本
2. **以合理价格买好公司** — ROCE>15% + 护城河 + 好管理层
3. **极度懒惰** — 95%时间不动，仅在护城河永久断裂时卖出

### 卖出条件（极少）
- 护城河永久受损
- 管理层诚信问题
- 原始投资论点被证伪
- **不因短期业绩下滑卖出，不因股价下跌卖出**

## 二、Benjamin Graham 价值投资（长线经典）

**出处**：Benjamin Graham,《The Intelligent Investor》(1949) +《Security Analysis》(1934)

**作者背景**：价值投资之父，巴菲特的导师

### 三大核心概念

| 概念 | 含义 |
|------|------|
| **安全边际** | 只在价格远低于内在价值时买入 |
| **Mr. Market** | 把市场当情绪化的对手方而非指导者 |
| **投资者 vs 投机者** | 投资需要分析和纪律，投机是猜测 |

### 量化筛选标准（8条）

| # | 标准 | 门槛 |
|---|------|------|
| 1 | 规模 | 营收>$1亿 |
| 2 | 财务实力 | 流动比率>2 |
| 3 | 盈利稳定性 | 过去10年每年盈利 |
| 4 | 分红记录 | 连续20年+不间断分红 |
| 5 | 盈利增长 | 10年增长>33% |
| 6 | PE适度 | <15x（3年平均利润） |
| 7 | PB适度 | <1.5x |
| 8 | 综合 | PE × PB < 22.5 |

### Graham内在价值公式

```
V = EPS × (8.5 + 2g) × 4.4 / Y

EPS = 每股收益(TTM)
g = 预期年增长率(%)
Y = AAA公司债收益率
```

### Graham vs 达尔文 对比

| 维度 | Graham | 达尔文 |
|------|--------|--------|
| 买什么 | 便宜的股票 | 优质的企业 |
| 核心指标 | PE/PB | ROCE |
| 安全边际 | 价格折扣 | 业务质量（护城河） |
| 何时卖 | 价格达内在价值 | 永不卖（除非护城河断裂） |
| 持仓 | 分散20-30只 | 集中10-15只 |
| 持有期 | 1-3年 | 无限期 |

## 三、SEC财报健康分析（中线量化）

**出处**：综合框架（整合Graham量化标准+Beneish/Altman学术模型）

### 10分钟健康快检

```
1. OCF > 净利润？ → 是=真实盈利
2. 负债/股东权益 < 2？ → 是=可存活
3. ROCE > 15%（5年）？ → 是=优质企业
4. 审计意见清洁？ → 是=数据可信
5. 应收/存货与营收同步？ → 是=无操纵

5个✅ = 通过健康筛选
任何❌ = 深入调查或排除
```

### 关键量化模型

**Altman Z-Score（破产风险）**：
```
Z = 1.2(WC/TA) + 1.4(RE/TA) + 3.3(EBIT/TA) + 0.6(Equity/Debt) + 1.0(Sales/TA)

Z > 2.99 = 安全    Z 1.8-2.99 = 灰色地带    Z < 1.8 = 困境
```

**Beneish M-Score（财务操纵概率）**：
```
M-Score > -1.78 = 可能操纵
M-Score < -1.78 = 可能正常
```

### 红旗清单

- 审计师更换（尤其年中）
- 应收增速>营收增速（虚假销售）
- 存货增速>营收增速（产品卖不动）
- OCF << 净利润（利润不真实）
- "一次性"费用年年出现
- 关联方交易

## 四、箱体操作系统（短线波段）

**出处**：综合框架（整合技术分析+风险管理纪律）

### 核心逻辑

```
识别箱体区间 → 箱底买入 → 箱顶卖出 → 严格止损
```

### 操作纪律（10条铁律）

| # | 规则 |
|---|------|
| 1 | 单票仓位≤30%（高波动≤20%） |
| 2 | 破箱底3%无条件止损 |
| 3 | 触箱顶先出2/3 |
| 4 | 已超过中轴不追 |
| 5 | 放量突破=新箱；缩量到顶=必卖 |
| 6 | 5个交易日无启动→平仓 |
| 7 | 周五不建仓 |
| 8 | 财报日不隔夜重仓 |
| 9 | 同时持仓≤3只 |
| 10 | 单月亏5%强制休息一周 |

### 信号组合

- **买入信号**：RSI<30 + 箱底附近 + 放量企稳
- **卖出信号**：RSI>70 + 箱顶附近 + 缩量滞涨
- **最佳建仓日**：周二/周三

## 五、日内交易系统

**出处**：Andrew Aziz,《How to Day Trade for a Living》, CreateSpace, 2015

**作者背景**：Bear Bull Traders创始人，物理学博士转职业日内交易员

### 7大核心策略

| 策略 | 入场条件 | 止损 |
|------|---------|------|
| ABCD形态 | C点确认支撑后入场 | C点下方 |
| 牛旗突破 | 旗面上沿突破+放量 | 旗面下沿 |
| VWAP回踩 | 价格回踩VWAP且趋势方向确认 | VWAP对面 |
| 开盘区间突破 | 5-15分钟区间突破 | 区间另一侧 |
| 顶底反转 | 超买/超卖极端+反转K线 | 极端价外 |
| 均线趋势 | 回踩9/20 EMA | 均线下方 |
| 支撑阻力 | 关键位反弹/突破 | 关键位对面 |

### 风险管理

| 规则 | 标准 |
|------|------|
| 单笔风险 | ≤账户1-2% |
| 风险回报比 | ≥2:1 |
| 每日最大亏损 | 硬性上限 |
| 连亏处理 | 连亏3笔→缩仓或停止 |
| 仓位公式 | 仓位 = 最大风险金额 ÷ (入场价-止损价) |

### 交易日结构

| 时间 | 活动 |
|------|------|
| 盘前1h | 看新闻、扫描器、建观察清单 |
| 9:30-10:00 | 观察开盘，等待形态 |
| 10:00-11:30 | 主交易窗口（波动最大） |
| 11:30-14:00 | 午间淡静，不交易 |
| 14:00-16:00 | 尾盘机会，新手应避免 |
| 收盘后 | 复盘+写日志 |

## 六、One Good Trade（职业日内交易）

**出处**：Mike Bellafiore,《One Good Trade》, Wiley, 2010

**作者背景**：SMB Capital联合创始人（纽约Prop Trading Firm），12+年培养职业交易员

### 核心概念

| 概念 | 含义 |
|------|------|
| **One Good Trade** | 不追求赚多少，只追求每笔执行质量 |
| **Stocks In Play** | 只交易今天有催化剂+放量的股票 |
| **Playbook** | 建立自己的交易剧本（形态+条件+目标） |
| **Reading the Tape** | 通过Level 2看真实买卖力量 |

### 交易员成长金字塔

```
        [精英交易员]
       /            \
    [一致性/持续盈利]
   /                  \
  [技能：读带、形态、执行]
 /                          \
[纪律 + 风险管理 + 心理韧性]
/                              \
[品格：诚实、勤奋、谦逊、求知欲]
```

### 复盘体系

| 频率 | 内容 |
|------|------|
| 每日 | 每笔交易回顾：是否One Good Trade？ |
| 每周 | 统计Win Rate、P&L、识别反复错误 |
| 每月 | 评估进步、更新Playbook、设定1-2个改进目标 |

### 风险管理哲学

- **心理资本比金钱资本更宝贵**
- 状态不好时缩仓，状态好时适度放大
- 绝不"报复交易"
- 保住资本="活着"是第一要务

## 七、交易心理学（贯穿全部）

**出处**：Mark Douglas,《Trading in the Zone》, Prentice Hall Press, 2000

**作者背景**：交易心理学先驱，1978年开始交易

### 五大基本真理

| # | 真理 | 含义 |
|---|------|------|
| 1 | 任何事都可能发生 | 没有100%确定的交易 |
| 2 | 赚钱不需要知道下一步 | 优势是概率性的 |
| 3 | 盈亏呈随机分布 | 赢和输随机穿插 |
| 4 | 优势=概率更高 | 优势≠确定性 |
| 5 | 每一刻都独一无二 | 过去不保证未来 |

### 核心修炼

| 修炼 | 方法 |
|------|------|
| 概率思维 | 像赌场老板思考：单次无关，样本量定成败 |
| 完全接受风险 | 下单前已把止损"花掉了"，止损后心态平静 |
| 消除恐惧贪婪 | 去掉对市场的期望，它做什么都不让你痛苦 |
| 进入Zone | 无所期望、完全专注、与市场流动对齐 |

### 行为偏差对策

| 偏差 | 解药 |
|------|------|
| 确认偏差 | 承认"任何事都可能发生" |
| 损失厌恶 | 真正接受风险 |
| 近因效应 | 每笔交易都是独立事件 |
| 过度自信 | 概率思维、样本量思维 |
| 分析瘫痪 | 执行比分析重要 |

## 补充：涨停板操作系统（A股短线专用）

**出处**：实战经验总结

### 六种形态强度排序

| 形态 | 强度 | 决策 |
|------|------|------|
| 一字板 | ★★★★★ | 全仓持有 |
| T字板 | ★★★★ | 持有70% |
| 早盘秒板 | ★★★★ | 持有70% |
| 上午震荡封板 | ★★★ | 持有50% |
| 午后封板 | ★★ | 卖出为主 |
| 高位烂板 | ★ | 全卖 |

### 烂板识别（最危险）

满足3条以上 = 烂板 = 必须全卖：
- 开板≥3次
- 回封时间越来越长
- 封单越来越少
- 换手率>15%
- 板块无联动
- 尾盘最后10分钟才封

## 补充：被动基金投资（最简方案）

**出处**：指数投资学术研究+实证数据

### 推荐组合

```
60% QQQ (纳斯达克100) + 30% VOO (标普500) + 10% SMH (半导体)
```

| 基金 | 10年年化 | 费率 | 适合 |
|------|---------|------|------|
| QQQ | ~18% | 0.20% | 科技增长时代首选 |
| VOO | ~13% | 0.03% | 最分散最稳 |
| SMH | ~25-30% | 0.35% | AI赛道但波动大 |

**核心认知**：被动基金长期跑赢大多数主动基金（费率低+不择时）

## 所有方法论共同的核心原则

无论选择哪套系统，以下6条是**共通的底层规律**：

| # | 原则 | 含义 |
|---|------|------|
| 1 | **风险管理第一** | 活着比赚钱重要。所有大师都把不亏钱放在赚钱前面。 |
| 2 | **纪律>聪明** | 最好的交易员不是最聪明的，而是最有纪律的。 |
| 3 | **过程>结果** | 关注执行质量而非单笔盈亏，长期结果是好过程的副产品。 |
| 4 | **认知自我** | 你最大的对手不是市场，是你自己的偏差和情绪。 |
| 5 | **持续学习** | 市场在变，你的系统也必须进化，但核心原则不变。 |
| 6 | **简单>复杂** | 能用3条规则解决的问题不要用30条。 |
