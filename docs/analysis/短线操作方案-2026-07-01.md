## 方法论依据

本方案整合三套经过验证的框架：

### 1. 达尔文Kill List（选股质量过滤器）
- **作用**：确保交易的底层标的有基本面支撑，跌了敢拿，涨了不怕踏空
- **核心**：只做Kill List过关的股票（✅），瑕疵股（⚠️）限制仓位和持仓时间

### 2. 箱体操作系统（进出场纪律）
- **作用**：定义买卖点、止损止盈、仓位控制
- **核心**：箱底买入 → 箱顶卖出 → 破箱底3%无条件止损

### 3. Mark Douglas概率思维（心理纪律）
- **作用**：避免报复性交易、追涨杀跌、移动止损
- **核心五大真理**：
  1. 任何事都可能发生
  2. 赚钱不需要知道下一步
  3. 盈亏呈随机分布
  4. 优势=概率更高≠确定性
  5. 每一刻都独一无二

## 操作纪律（铁律 — 违反必须反思）

```
┌─────────────────────────────────────────────────────┐
│  10条铁律                                            │
├─────────────────────────────────────────────────────┤
│  1. 单票仓位 ≤ 30%（高波动票 ≤ 20%）                │

│  4. 已脉冲启动超过箱体中轴的不追                      │
│  5. 放量突破箱顶=可能开新箱；缩量到箱顶=必卖          │
│  6. 买入后5个交易日无启动 → 平仓换股                  │
│  7. 周五不建仓                                       │
│  8. 财报日不隔夜重仓                                  │
│  9. 同时持仓 ≤ 3只                                   │
│  10. 单月亏损5% → 强制休息一周                        │
└─────────────────────────────────────────────────────┘

仓位计算公式（Aziz风控）:
  仓位股数 = 最大单笔风险金额 / (入场价 - 止损价)
  最大单笔风险 = 可用资金 × 1.5% = $50,000 × 1.5% = $750
```
