## 达尔文投资法方法论回顾

```
投资决策流程:
[1] Kill List排除 → 触犯任何一条？→ 放弃
[2] ROCE持续>15%？(5年以上) → 否？→ 放弃
[3] 护城河来源清晰？可持续？ → 不确定？→ 放弃
[4] 管理层诚信+能力？ → 有疑问？→ 放弃
[5] 估值合理？ → 太贵？→ 加入观察清单
[6] 买入，然后极度懒惰

Kill List 10条排除标准:
#1 管理层不诚信        #2 高杠杆
#3 连续并购型          #4 行业变化过快
#5 困境反转型          #6 利益不一致
#7 国企               #8 单一客户依赖
#9 模式复杂难懂        #10 欺诈/操纵历史

正面评估维度:
① ROCE持续>15% (5年以上)
② 护城河来源清晰且可持续
③ 管理层诚信+能力
④ 财务强度(低负债+高自由现金流)
⑤ 增长可自我融资(有机增长>并购)
```

## 纳指Top20 逐家达尔文基本面分析

### 1. GOOGL — Alphabet（搜索/广告/AI）

| 维度 | 评估 |
|------|------|
| Kill List | 全部通过。#9复杂度边界情况，但核心收入(广告)极清晰 |
| 5年ROCE | 25-30%，持续高于15% |

| 可持续性 | 强。搜索习惯根深蒂固，AI搜索是增强非威胁；YouTube无对手 |

| 财务 | 净现金$1000亿+，FCF $70B+/年，零债务压力 |
| 增长 | 有机为主，云计算+AI是核心引擎 |
| 风险 | 反垄断诉讼；AI对广告模式的长期影响 |
| **结论** | ✅ 完全过关，短线+长线均可 |
