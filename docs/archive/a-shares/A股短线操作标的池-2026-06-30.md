# A股短线操作标的池 — 20只精选

分析日期：2026年6月30日
资金规模：约¥119,000（1手茅台等值）

---

## 背景：为什么不做茅台弹性仓

- 茅台日振幅仅1.5-2%，短线效率低
- 当前趋势向下（月跌9.5%），做反弹胜率<50%
- 心理上与亏损底仓绑定，容易影响纪律
- 结论：用同等资金做高振幅+趋势向好的标的，效率高2-3倍

中信证券预判下半年"结构性慢牛"继续。6/26经历急跌洗盘（上证-2.26%，创业板-4.07%），是上涨途中的回调买点。

## 选股标准

- 日振幅3-5%（中盘为主）
- 近期有明确催化（政策/业绩/板块轮动）
- 趋势向上或震荡（不做下跌趋势的标的）
- 与茅台/白酒板块低相关（分散风险）

## 操作框架

```
资金: ¥119,000

分配:
  单只最大仓位: ¥40,000（约33%）
  同时持仓: 最多2只
  每只目标利润: 5-8%
  止损: -3%（绝对纪律）

轮动逻辑:
  板块启动信号 → 从该板块选1-2只 → 买入 → 目标到或5天无动→出

  机器人消息(特斯拉/政策) → 绿的谐波/拓普集团
  美股AI芯片暴涨         → 澜起科技/景嘉微
  低空政策发布            → 纵横股份/山河智能
  新能源急跌企稳          → 恩捷股份
  地缘事件               → 高德红外/航发动力
```

---

## 操作纪律（A股版）

```
1. 单票仓位 ≤ 33%（¥40,000）
2. 同时持仓 ≤ 2只
3. 止损 -3% 无条件执行（T+1无法当日纠错，止损更重要）
4. 目标利润 5-8% 分批出（到5%出一半，到8%全出）
5. 5个交易日无启动 → 平仓换股
6. 尾盘14:30后决策买入（减少T+1隔夜风险）
7. 周五不建仓
8. 连续两次止损 → 停止操作两周
9. 第一周用小仓位(¥20,000)试手
10. 每次操作记录：买入理由、卖出理由、盈亏金额
```
