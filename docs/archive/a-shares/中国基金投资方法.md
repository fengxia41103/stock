# 中国基金不定期不定额定投 — 方法论与基金池

分析日期：2026年7月1日

---

## 第一部分：方法论框架

### 核心思想：不定期不定额 ≠ 随意买

"不定期不定额"不是随心所欲，而是**有规则的灵活投入**——便宜时多买，贵时少买或不买。

---

### 三种经验证的智慧定投策略

#### 策略一：估值定投法（PE/PB百分位）

```
核心逻辑：指数便宜时多买，贵时少买/卖出

操作规则：
  PE百分位 0-10%  → 投入基准金额的 200%（极度低估）
  PE百分位 10-20% → 投入基准金额的 150%
  PE百分位 20-30% → 投入基准金额的 100%（正常投入）
  PE百分位 30-50% → 投入基准金额的 50%
  PE百分位 50-70% → 停止投入，持有不动
  PE百分位 70%+   → 分批卖出（每上升10%卖出1/3）

数据来源：且慢/蛋卷基金/天天基金 均提供指数估值百分位
```

#### 策略二：均线偏离法

```
核心逻辑：价格低于均线时多买，高于均线时少买

公式：偏离度 = (当前价格 - 250日均线) / 250日均线

操作规则：
  偏离度 < -20%  → 投入 200%
  偏离度 -20%~-10% → 投入 150%
  偏离度 -10%~0%  → 投入 100%
  偏离度 0%~+10%  → 投入 50%
  偏离度 > +10%   → 暂停投入
  偏离度 > +20%   → 开始分批止盈
```

#### 策略三：目标收益止盈法

```
核心逻辑：设定目标收益率，达到即止盈，重新开始

操作规则：
  持仓收益达 +20% → 卖出50%，剩余继续持有
  持仓收益达 +30% → 全部卖出
  卖出资金 → 存入"弹药库"等下一轮低估时投入
  
  止损：持仓亏损达 -30% → 不卖！反而加倍投入（前提：指数基金）
```

---

### 纪律规则

```
1. 设定"基准金额"（如每次¥3,000-5,000）
2. 不追涨：指数涨超10%后不加仓
3. 分散：同时定投3-5只不同类型基金
4. 单只基金占总投入不超过30%
5. 留20%现金作为"恐慌加仓弹药"
6. 每季度检视一次，不频繁操作
```

### 选择主动基金的核心原则

```
✅ 选经理，不选基金名字
✅ 看5年+年化，不看1年排名（冠军魔咒）
✅ 最大回撤<30%（回撤太大拿不住）
✅ 规模10-300亿最佳（太小不稳，太大船大难掉头）
✅ 基金经理持有自己基金（利益绑定）
❌ 不买任职<3年的新经理
❌ 不买一年翻倍的热门基金（均值回归必来）
```

### 定投建议

```
从Top 10中选3-4只，风格分散：

组合示例：
  朱少醒(均衡) + 赵蓓(医药) + 孙迪(制造) + 何帅(低波动)
  
每只每月¥2,000-3,000
低估时(基金净值低于250日均线)加倍
高估时(收益>30%)止盈一半
```

## 第四部分：新基金认购策略分析

### 新基金是什么？

新基金 = 首次发行的基金，以**1元/份**净值起步，经历认购期→封闭期→开放申赎。

### 新基金值不值得买？

| 情况 | 结论 | 理由 |
|------|------|------|
| 明星经理的新基金 | ⚠️ 谨慎 | 有历史业绩可查的老基金更好，新基金有建仓期拖累 |
| 新赛道/新指数基金 | ✅ 值得关注 | 如REITs指数基金、机器人ETF——老基金没有的品种 |
| 限额配售的爆款 | ❌ 不追 | 规模太大反而是业绩杀手 |
| 3年封闭期基金 | ⚠️ 看经理 | 锁定期长，只有顶级经理值得信任 |
| 发起式基金(经理跟投) | ✅ 加分 | 利益绑定，经理自己买≥1000万 |

### 当前值得关注的新基金类型（2026年下半年）

#### 1. REITs指数基金（2026年5月刚获批，即将发行）

```
背景：
  - 2026年5月18日证监会正式受理首批4只REITs指数基金
  - 基金公司：华夏、中金、易方达、南方
  - 跟踪：中证REITs全收益指数（含53只REITs，市值1695亿）
  - 特点：分红收益+资本增值，2025年平均分红率>5%
  
为什么值得认购：
  ✅ 填补市场空白——之前没有REITs指数基金
  ✅ 降低门槛——单只REITs数万元起，指数基金1元起
  ✅ 分散风险——一只基金覆盖53只REITs
  ✅ 高分红——底层资产强制分红90%+
  ✅ 国际经验——美国REITs指数基金是成熟配置品种
  
操作建议：
  发行时认购¥10,000-20,000
  封闭期结束后根据表现决定是否加仓
  适合作为"固收+"替代品长期持有
```

#### 2. 新行业ETF（如机器人ETF、低空经济ETF）

```
判断标准：
  ✅ 行业处于爆发初期（渗透率<5%）
  ✅ 没有同类老基金可替代
  ✅ 基金公司ETF管理能力强（华夏/易方达/华泰柏瑞）
  
风险：
  ❌ 行业主题可能昙花一现
  ❌ 建仓期可能买在高位
  → 限额投入，不超过总投入的10%
```

### 认购新基金的操作纪律

```
认购前检查清单：
  □ 基金经理有5年+可查业绩？（新人不买）
  □ 是否有同类老基金替代？（有则买老不买新）
  □ 封闭期多长？能接受吗？
  □ 认购费率 vs 已有基金申购费？
  □ 是否限额配售？（爆款≠好基金）
  □ 基金经理是否跟投？（发起式加分）

操作原则：
  1. 新基金只投总资金的10-15%
  2. 优先选"老基金没有的品种"（如REITs指数）
  3. 明星经理新发 → 不如买其管理的老基金
  4. 封闭期基金 → 只买3年期以内的
  5. 认购后别急着看收益——建仓期3-6个月正常波动
```

## 第五部分：综合配置建议

假设每月可投¥10,000：

```
核心层(50%): ¥5,000/月
  沪深300ETF(510300) ¥2,500 + 中证500增强(161017) ¥2,500
  → 用估值定投法，PE低多买高少买

卫星层(30%): ¥3,000/月
  主动基金3选2轮换：
  朱少醒(161005) / 谢治宇(163406) / 何帅(519697)
  → 净值低于250日均线时投入，高于时暂停

机会层(20%): ¥2,000/月
  REITs指数基金（发行时一次性认购¥15,000-20,000）
  + 科创50ETF（等回调至PE百分位<40%时再投入）

现金储备: 保留2-3万随时可用
  → 市场暴跌时（如6/26那种-4%大跌）一次性加倍投入
```
