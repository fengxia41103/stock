```

  → 纯短线操作，绝不转为长线持有
  → 严格止损，不因"基本面好"而扛单（因为基本面本身就有问题）
  → 用更小仓位(≤20%)，更短持仓周期(1-5天)
```

```
┌─────────────────────────────────────────────────────────────┐
│  第一梯队：进攻主力（占短线资金40%）                           │

├─────────────────────────────────────────────────────────────┤
│  第二梯队：稳健核心（占短线资金35%）                           │
│  ─────────────────────────────────────────────              │
│  AMAT / LRCX / KLAC（三选一或二）                             │
│  特点: 振幅5-6%，半导体设备寡头，基本面扎实                    │
│  用法: 设备订单周期+出口管制事件驱动，持仓3-5天                │

├─────────────────────────────────────────────────────────────┤
│  第三梯队：防守反击（占短线资金25%）                           │
│  ─────────────────────────────────────────────              │
│  CRWD / PANW / MSFT / GOOGL                                 │
│  特点: 振幅2.5-5%，护城河深，回撤可控                         │
│  用法: 大盘急跌时抄底权重股，持仓5-7天等反弹                   │

实战组合示例（同时最多持3只）:

  激进模式: MRVL + AMAT + CRWD     → 高弹性，日波动可达±5%
  均衡模式: AMD + LRCX + MSFT      → 攻守兼备
  稳健模式: MSFT + GOOGL + PANW    → 回撤小，适合新手练手

轮动逻辑:
  AI行情启动   → 第一梯队(MRVL/AMD/QCOM)出击
  半导体恐慌   → 第二梯队(AMAT/LRCX/KLAC)抄底
  大盘普跌     → 第三梯队(MSFT/GOOGL)接盘
  全部在箱顶   → 空仓等待，不操作就是最好的操作
```

### 使用说明

```
Top 3 (MRVL/QCOM/AMD): 超高波动，一天可能±5-10%
  → 最小仓位(≤15-20%)，最严止损(2-3%)，持仓1-3天
  → 适合有盘中看盘时间的交易者

Top 4-6 (KLAC/LRCX/AMAT): 半导体设备三巨头
  → 往往同步涨跌，选一只做即可，不要同时持有三只
  → 基本面扎实，急跌可以稍微放宽止损

Top 7-10 (CRWD/PANW/CDNS/ADI): 中高波动+基本面较好
  → 适合不能整天看盘的交易者
  → 可持有3-7天等箱体完成
```
