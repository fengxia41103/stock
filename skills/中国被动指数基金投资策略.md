## 定投策略

```
最佳定投标的: 沪深300 + 创业板指（波动大=定投效果好）

定投频率: 每周或每两周一次
定投金额: 固定金额，不因涨跌改变

加仓规则（越跌越买）:
  - 指数PE低于历史30%分位 → 定投金额×1.5
  - 指数PE低于历史10%分位 → 定投金额×2.0
  - 指数PE高于历史70%分位 → 定投金额×0.5
  - 指数PE高于历史90%分位 → 停止定投，开始分批卖出

查看估值: 
  - 支付宝/天天基金 → 指数估值页面
  - 且慢/蛋卷基金 → 指数温度计
```

## 中国 vs 美国被动基金核心差异

| 维度 | 美国(SPY/QQQ) | 中国(沪深300/创业板) |
|------|-------------|-------------------|
| 长期趋势 | 持续向上（200年牛市） | 牛短熊长，箱体震荡 |
| 最佳策略 | 买入并持有(Buy & Hold) | 定投+估值择时 |
| 费率 | 0.03-0.20% | 0.15-0.50% |
| 分红 | 季度/年度分红 | 不稳定 |
| T+0 | 美股T+0 | A股ETF T+1 |
| 关键区别 | **被动持有即可** | **需要估值纪律，高估止盈** |

> ⚠️ 核心认知：A股被动基金**不能无脑持有**（与美股不同）。必须结合估值分位做"低买高卖"，否则可能持有5年还亏钱（如2015年高点买入）。
