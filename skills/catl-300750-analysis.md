## 四、主要风险

1. **技术颠覆风险**：固态电池若由外部玩家率先商业化（但CATL自身也在推进）
2. **地缘政治**：美国IRA法案限制、欧洲反补贴调查（匈牙利工厂在建中对冲）
3. **价格战**：比亚迪弗迪电池垂直整合，二线厂商低价抢份额
4. **原材料波动**：锂价虽已回落，但长期供需仍有不确定性
5. **客户集中在新能源车**：行业增速放缓时量增可能减速（储能业务是第二增长曲线）

## 五、总结

```
排除清单：         ✅ 通过（"快速变化行业"需关注但CATL主动引领变化）
ROCE/ROE > 15%：  ✅ ROE约24%，持续多年
护城河：           ✅ 规模+技术+转换成本，极强
管理层：           ✅ 创始人主导，利益一致，执行力强
估值：             ✅ PE 22倍，PEG 0.52，历史低位
```

**结论：宁德时代符合Pulak Prasad框架中"高质量公司以合理价格买入"的标准。** 主要争议点在于电池行业是否属于"快速变化行业"——CATL的策略是"引领变化而非被变化淘汰"（全路线布局+巨额研发），这与纯粹的被动型科技企业不同。

当前PE 22倍 vs 历史均值46倍、利润增速42%、经营现金流远超净利润、合同负债暴增77%预示强劲未来订单——如果接受"CATL能持续引领电池技术"这个前提，当前价位具有吸引力。
