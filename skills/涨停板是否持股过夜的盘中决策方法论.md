# 涨停板"是否持股过夜"的盘中决策方法论

核心问题：封涨停后，盘中如何判断"这只是起步还是已经到顶"，从而决定持有还是卖出。

---

## 一句话原则

> **封板质量越高 → 后续空间越大 → 应该持有不卖。**

---

## 盘中判断：7维评分模型

在涨停封住后，逐项打分（满分14分），**≥10分持有，<10分卖出**。

---

### ① 封单强度（0-2分）

```
封单金额 / 当日成交金额

> 3倍   → 2分（超强，卖盘枯竭）
1-3倍   → 1分（正常）
< 1倍   → 0分（弱，随时可能开板）
```

---

### ② 封板时间（0-2分）

```
一字板 / 开盘30分钟内封板   → 2分
上午封板（10:30前）          → 1.5分
午后封板（13:00后）          → 0.5分
尾盘封板（14:30后）          → 0分
```

越早封板，主力控盘力越强，后续空间越大。

---

### ③ 开板次数（0-2分）

```
全天未开板（一封到底）    → 2分
开板1次后回封              → 1分
开板2次以上/反复开关       → 0分（分歧大，风险高）
```

---

### ④ 板块联动（0-2分）

```
同板块3只以上涨停     → 2分（板块效应，资金主线）
同板块1-2只涨停       → 1分
独涨，板块无联动       → 0分（个股行为，不可持续）
```

---

### ⑤ 位置与量价（0-2分）

```
低位首板（离前高>30%） + 放量  → 2分（启动信号）
中位首板 + 温和放量            → 1分
高位板（已连续上涨30%+）       → 0分（可能是最后一板）
缩量板（换手<3%）              → 加0.5分（惜售，筹码锁定好）
```

---

### ⑥ 成交量与换手率（0-2分）【新增】

盘中实时可查的硬数据，反映筹码交换的真实程度。

```
换手率判断：
├─ 换手率 3-8% + 量比>2   → 2分（健康放量，新资金进场承接）
├─ 换手率 < 3%（缩量封板） → 1.5分（惜售，抛压极小，但需确认非无人问津）
├─ 换手率 8-15%            → 1分（分歧换手，有承接但抛压也大）
└─ 换手率 > 15%            → 0分（巨量换手，主力可能在出货）

配合成交量形态：
├─ 封板前放量、封板后缩量  → 加0.5分（攻击有力，封住后卖盘消失）
├─ 封板后仍有大量成交      → 减0.5分（封单在不断被消耗）
```

**关键信号：**
- 低位首板换手5-8%是最健康的——说明有足够换手完成筹码交换，但没有过度抛压
- 连板股缩量（换手<5%）是强势信号——说明前一天买入者不愿卖出
- 高换手（>15%）涨停要警惕——可能是主力对倒拉升出货

---

### ⑦ 资金流向（0-2分）【新增】

通过Level-2数据或交易软件实时查看主力资金净流入/流出。

```
主力净流入判断（大单+特大单净买入）：
├─ 主力净流入 > 当日成交额的20%   → 2分（主力强势吸筹）
├─ 主力净流入 10-20%               → 1.5分（主力有参与）
├─ 主力净流入 0-10%                → 1分（中性，散户为主）
├─ 主力净流出（大单在卖）           → 0分（主力借涨停出货！）

辅助判断：
├─ 超大单（>100万元）持续净买入    → 加0.5分
├─ 涨停后大单挂卖反复撤单          → 减0.5分（试探性出货）
├─ 尾盘最后30分钟主力突然净流出    → 强烈卖出信号
```

**关键信号：**
- 封板时如果**大单持续挂买且不撤单** → 真实买入意愿
- 封板时如果**大单频繁挂了又撤** → 虚假封单，诱多
- **龙虎榜预判**：如果能看到买入席位以机构/知名游资为主 → 大幅加分

## 评分→仓位决策（14分制）

```
≥ 12分 → 全仓持有（高质量板，大概率有后续）
10-11分 → 持有70%，卖出30%
 8-9分 → 持有50%，卖出50%
 6-7分 → 持有30%，卖出70%
 < 6分 → 果断全部卖出落袋
```

**永远不要"全持"或"全卖"，用比例反映你的信心程度。**

---

## 次日验证与动态调整

持有过夜后，次日的操作规则：

```
次日走势              →  操作
──────────────────────────────────
高开5%+直接封板       →  继续持有（连板确认）
高开3-5%回踩企稳      →  持有，止损设前日涨停价-2%
高开后冲高回落>5%     →  立刻卖出（冲高出货信号）
平开/低开             →  开盘30分钟内不破-3%则持有，否则卖
低开>3%               →  无条件卖出
```

---

## 不同类型涨停的持有概率参考

| 类型 | 次日高开概率 | 建议持仓比例 |
|------|-------------|-------------|
| 一字板（集合竞价即封） | ~80% | 全仓持有 |
| 开盘30分钟内封死不开 | ~60% | 70%持有 |
| 上午封板，开过1次 | ~45% | 50%持有 |
| 午后封板 | ~30% | 30%或不持有 |
| 尾盘封板/烂板反复开关 | ~20% | 全卖 |

---

## 7维模型速查对照表

| 维度 | 强信号（满分） | 危险信号（0分） |
|------|---------------|----------------|
| 封单强度 | 封单>成交3倍 | 封单<成交额 |
| 封板时间 | 30分钟内封住 | 14:30后才封 |
| 开板次数 | 一封到底 | 反复开关2次+ |
| 板块联动 | 3只以上同涨停 | 独涨无联动 |
| 位置量价 | 低位首板+放量 | 高位连涨30%+ |
| 换手率 | 3-8%健康换手 | >15%巨量换手 |
| 资金流向 | 主力净流入>20% | 主力净流出 |

---

## 总结

> **不是"预测后面还涨不涨"，而是"封板质量告诉你概率是多少"。**
>
> 7个维度 = 3个传统指标（封单、时间、开板）+ 2个环境指标（板块、位置）+ 2个资金指标（换手、流向）
>
> 前5维看"板的质量"，后2维看"钱的真实意图"。两者共振时信号最强。
>
> 用**分仓**对冲判断失误：永远不要"全持"或"全卖"，用比例反映你的信心程度。
