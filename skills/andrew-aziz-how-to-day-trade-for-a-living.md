# How to Day Trade for a Living

Andrew Aziz (2015) — Bear Bull Traders 创始人，物理学博士转职业日内交易员

---

## 核心理念

Day trading 不是赌博，不是副业，是一份全职工作。需要纪律、工具、策略和持续学习。

**三个前提：**
1. Day trading 不是快速致富的捷径
2. 它是一项极其消耗脑力的工作，需要像运动员一样训练
3. 持续盈利可能需要 6-24 个月的学习曲线

## 第一部分：基础设施

### 必备工具

| 工具 | 用途 |
|------|------|
| 直连交易平台 (DAS Trader, Sterling) | 快速下单，Level 2 数据 |
| 实时扫描器 (Trade Ideas, Finviz) | 盘前筛选 In Play 股票 |
| Level 2 / Time & Sales | 看买卖盘深度和成交流 |
| 图表软件 | 1分钟/5分钟K线，技术指标叠加 |
| 新闻源 | 催化剂识别（财报、FDA、合同） |

### 选股标准（Stocks In Play）

每天只交易少数几只"活跃股"：
- 盘前有催化剂（新闻、财报、升级/降级）
- 盘前成交量 > 正常水平
- 有相对强度或弱势（vs SPY）
- ATR（平均真实波幅）足够大以覆盖交易成本

## 第二部分：核心交易策略

### 1. ABCD Pattern（ABCD 形态）

最基本的价格形态：
```
A → B（上涨）→ C（回调）→ D（再次上涨）
```
- 入场：C 点确认支撑后
- 止损：C 点下方
- 目标：AB 等距延伸

### 2. Bull Flag Momentum（牛旗动量）

```
强势上涨 → 窄幅横盘整理（旗面）→ 突破继续
```
- 入场：旗面上沿突破 + 放量
- 止损：旗面下沿
- 目标：旗杆等距

### 3. VWAP Trading（成交量加权均价）

VWAP 是机构的成本线：
- 价格 > VWAP → 多头偏向
- 价格 < VWAP → 空头偏向
- VWAP 回踩 → 趋势方向入场

### 4. Opening Range Breakout（开盘区间突破）

- 等待开盘后 5-15 分钟形成区间
- 区间突破方向入场
- 止损：区间另一侧

### 5. Top/Bottom Reversal（顶底反转）

- 识别超买/超卖极端
- 等待反转K线确认（锤子线、吞没等）
- 配合 Level 2 大单信号

### 6. Moving Average Trend（均线趋势）

- 9 EMA / 20 EMA 作为短期趋势参考
- 价格回踩均线 = 趋势入场机会
- 均线死叉 = 退出信号

### 7. Support & Resistance（支撑阻力）

- 整数关口、前日高低、盘前高低
- 支撑位做多，阻力位做空
- 突破 + 回踩确认 = 高概率入场

## 第三部分：风险管理

**核心规则：**

| 规则 | 内容 |
|------|------|
| 单笔风险 | 不超过账户 1-2% |
| 风险回报比 | 至少 2:1（风险1赚2） |
| 每日最大亏损 | 设定硬性上限，到了就停 |
| 连亏处理 | 连亏3笔 → 缩小仓位或停止交易 |
| 止损必须 | 入场前必须明确止损位，不移动止损 |

### 仓位计算

```
仓位大小 = 最大风险金额 / (入场价 - 止损价)
```

例：账户 $25,000，最大风险 1% = $250
入场 $50.00，止损 $49.50（风险 $0.50/股）
仓位 = $250 / $0.50 = 500 股

## 第四部分：交易心理

### 新手常犯的致命错误

1. **过度交易** — 无聊时乱开仓
2. **报复性交易** — 亏了想立刻赚回来
3. **移动止损** — 不愿承认错误
4. **加仓亏损仓位** — "摊平"是自杀行为
5. **跳过盘前准备** — 没有计划就是计划失败

### 正确心态

- 每天只要做好"几笔好交易"就够了
- 亏损是成本，不是失败
- 关注过程（执行质量），不关注结果（今天赚多少）
- 写交易日志，每天复盘

## 第五部分：交易日结构

| 时间 | 活动 |
|------|------|
| 盘前 1h | 看新闻、跑扫描器、建观察清单 |
| 9:30-10:00 | 观察开盘动态，等待形态形成 |
| 10:00-11:30 | 主要交易窗口（波动最大） |
| 11:30-14:00 | 午间淡静，通常不交易 |
| 14:00-16:00 | 尾盘可能有机会，但新手应避免 |
| 收盘后 | 复盘、写日志、更新统计 |

## 一句话总结

> **Day trading 是一份技能型工作：用正确的工具选正确的股票，在正确的位置下单，严格控制风险，日复一日地重复。**
