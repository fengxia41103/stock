# 涨停后再入场的系统方法

适用场景：涨停板卖出后，判断是否回接以及如何回接抓后续涨停。

---

## 核心认知

**第一个涨停卖出是正确的操作。** 问题不是"不该卖"，而是需要一套"卖出后如何判断是否回接"的规则。

---

## 三种回接模型

### 模型一：涨停次日竞价回接法（最激进）

适用：强势题材首板，市场情绪好

```
判断条件（次日集合竞价9:15-9:25）：
├─ 竞价量 > 前日涨停封单量的30%？
├─ 竞价价格 > 前日收盘价（高开）？
├─ 竞价不低于 -2%？
└─ 同板块是否有其他涨停/大涨联动？

若4条中满足3条以上 → 9:25竞价买入
止损：日内跌破前日涨停价的-3%
止盈：再封涨停则持有；冲高回落5%则卖
```

---

### 模型二：分时回踩确认法（稳健）

适用：涨停次日或后续几天

```
涨停次日开盘后观察：

情况A：高开后回踩不破涨停价 → 买入
  ┌─ 高开 2-5%
  ├─ 回踩到涨停价附近（±1%）
  ├─ 缩量企稳（量能缩至前30分钟的1/3以下）
  └─ 再次放量上攻时 → 买入
  止损：跌破涨停价 -2%

情况B：高开后直接封板 → 排板买入
  ┌─ 高开 3%+
  ├─ 量能持续放大
  └─ 封涨停板 → 挂单排队买入
  止损：次日若低开-3%以下离场

情况C：低开或平开 → 不参与，等模型三
```

---

### 模型三：回调买入法（最安全）

适用：错过了模型一二，或首板后震荡调整

```
涨停后2-5日内：
├─ 股价回踩至涨停价×0.93-0.97 之间
├─ 成交量萎缩至涨停日的1/3以下
├─ 均线（5日线）开始走平或上翘
└─ 满足以上条件 → 买入

止损：跌破涨停启动日的开盘价
目标：再次冲击前高或新涨停
```

---

## 通用操作流程图

```
第一个涨停卖出后
        │
        ▼
次日集合竞价判断
        │
    ┌───┼───┐
    ▼       ▼       ▼
  高开3%+  高开0-3%  低开/平开
    │       │         │
  竞价买   开盘观察   不动
  (模型一)     │         │
            ▼         ▼
        回踩涨停价    等2-5日
        企稳买入     回调缩量
        (模型二A)    再买入
                    (模型三)
```

---

## 仓位与止损纪律

| 规则 | 说明 |
|------|------|
| **回接仓位** | 不超过原仓位的50-70%（已落袋利润，回接用利润部分博弈） |
| **止损幅度** | 统一设为买入价-5%，不犹豫 |
| **只做一次回接** | 回接后被止损 → 彻底放弃该标的，不反复 |
| **题材确认** | 必须有明确板块联动，独涨不追 |

---

## 心态管理

> **卖飞是交易系统的一部分，不是错误。**
>
> 回接是"新的交易"，用新的止损逻辑管理，不要因为"前面赚过"就放松风控。
>
> 统计上，A股首板次日成功连板的概率约15-25%。大多数时候不回接是对的。只在条件严格满足时才动手。
