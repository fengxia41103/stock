# 涨停板分类识别与决策方法

盘中实时识别涨停板类型，辅助做出持有/卖出决策。

---

## 涨停板六种形态速查

| 形态 | K线特征 | 强度 | 决策倾向 |
|------|---------|------|----------|
| **一字板** | 开=高=低=收=涨停价 | ★★★★★ | 全仓持有 |
| **T字板** | 涨停开→盘中开板→回封 | ★★★★ | 持有70% |
| **早盘秒板** | 低开/平开→30分钟内封死不开 | ★★★★ | 持有70% |
| **上午震荡封板** | 震荡后上午封住，开板≤1次 | ★★★ | 持有50% |
| **午后封板** | 下午才封涨停 | ★★ | 卖出为主 |
| **高位烂板** | 反复开关3次以上/尾盘封 | ★ | 全卖 |

---

## 盘中实时识别流程

### 第一步：集合竞价判断（9:15-9:25）

```
9:20观察竞价情况：

竞价价 = 涨停价 + 封单>流通盘1%
  → 预判：一字板（9:30确认）
  → 决策：如果已持仓，不要挂卖单

竞价价 = 涨停价 + 封单较小（<0.5%）
  → 预判：可能开盘后会打开变T字板
  → 决策：观望，不急于判断

竞价价 < 涨停价（正常高开/平开/低开）
  → 预判：不会是一字板，看盘中能否封板
  → 决策：按分时走势判断
```

### 第二步：开盘确认（9:30-9:35）

```
开盘价 = 涨停价 且 5分钟内未打开
  → 当前状态：一字板
  → 操作：持有，不卖

开盘价 = 涨停价 但 1-5分钟内打开过
  → 当前状态：T字板
  → 操作：观察回封速度

开盘价 ≠ 涨停价
  → 当前状态：非涨停开盘
  → 操作：等待是否盘中封板
```

### 第三步：盘中动态跟踪（9:35-15:00）

```
持续监控三个指标：
├─ 价格：是否一直贴着涨停价不动
├─ 封单变化：封单在增加还是被消耗
└─ 开板次数：打开过几次
```

## 5个实时指标区分6种形态

| 指标 | 一字板 | T字板 | 早盘秒板 | 上午震荡板 | 午后板 | 高位烂板 |
|------|--------|-------|----------|-----------|--------|----------|
| **开盘价** | =涨停价 | =涨停价 | <涨停价 | <涨停价 | <涨停价 | <涨停价 |
| **首次封板时间** | 9:25竞价 | 9:25竞价 | <10:00 | 10:00-11:30 | >13:00 | 不定 |
| **开板次数** | 0次 | 1-2次 | 0次 | ≤1次 | 0-1次 | ≥3次 |
| **最低价** | =涨停价 | <涨停价 | <涨停价 | <涨停价 | <涨停价 | <涨停价 |
| **封单趋势** | 持续增加 | 减后回增 | 稳定或增 | 稳定 | 缓慢减少 | 反复增减 |

## 高位烂板专项识别（最危险！）

烂板是出货信号，必须识别并果断卖出。

### 烂板特征（满足3条以上 = 烂板）

```
□ 开板次数 ≥ 3次
□ 每次回封所需时间越来越长（1分钟→5分钟→15分钟）
□ 每次回封后封单比前一次更少
□ 封板期间有大单频繁撤单
□ 已处于高位（连续上涨>20%或距前高<10%）
□ 换手率 > 15%（巨量，主力在对倒出货）
□ 板块无联动（独自表演）
□ 尾盘最后10分钟才封住（人为做K线）
```

### 烂板 vs 好板本质区别

| | 好板（一字/秒板） | 烂板 |
|--|--|--|
| 主力意图 | 锁仓拉升 | 借涨停出货 |
| 封单 | 真实且持续增加 | 虚假，频繁撤挂 |
| 开板后回封 | 快速（秒回） | 越来越慢 |
| 成交量 | 缩量或适度放量 | 巨量 |
