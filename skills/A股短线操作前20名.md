## 筛选方法论

```
短线脉冲股特征:
[1] 日均振幅 > 3%（近60日）
[2] 日均成交额 > 15亿（流动性保证进出）
[3] 题材/事件驱动明显（政策/业绩/行业催化频繁）
[4] K线形态呈现明显箱体震荡或脉冲-回落规律
[5] 换手率高（日均>2%）→ 资金博弈活跃
[6] 非单边趋势股（单边涨/跌不适合箱体操作）
```

## 各标的脉冲交易要点

### 1. 宁德时代 (300750) — 新能源风向标

**脉冲驱动因素：** 储能政策/电池技术突破/海外建厂/价格战传闻/特斯拉订单
**典型脉冲模式：** 政策出台→2-3日急拉10-15%→高位震荡3-5日→回落至箱体中轴
**最佳买点：** 行业利空(价格战/产能过剩)导致恐慌性杀跌至箱底
**止损位：** 破箱底5%即止损（185以下）

### 2. 中际旭创 (300308) — AI算力弹性最大

**脉冲驱动因素：** 英伟达财报/北美云厂商资本开支/新品发布/订单传闻
**典型脉冲模式：** AI催化→连续涨停或接近涨停→5-7日内回落30%+
**最佳买点：** AI恐慌叙事(资本开支削减)导致急跌至箱底
**止损位：** 破105即止损，此股波动极大需严控仓位(≤5%)

### 3. 比亚迪 (002594) — 新能源车龙头

**脉冲驱动因素：** 月度销量数据/海外市场突破/新车型发布/补贴政策
**典型脉冲模式：** 销量超预期→3-5日拉升8-12%→横盘消化→等待下一催化
**最佳买点：** 价格战加剧/单月销量不及预期的恐慌回调

### 4. 隆基绿能 (601012) — 光伏超跌反弹

**脉冲驱动因素：** 产能出清政策/硅料价格企稳/海外装机数据/贸易壁垒
**典型脉冲模式：** 长期阴跌→政策催化→急拉20-30%→再度回落
**最佳买点：** 行业极度悲观+政策底出现信号时
**⚠️注意：** 趋势向下时箱体会逐步下移，需确认企稳

### 5. 东方财富 (300059) — 市场情绪放大器

**脉冲驱动因素：** 大盘成交额/资本市场改革政策/牛市预期
**典型脉冲模式：** 成交额>1万亿→东财领涨券商板块→成交缩量后回落
**最佳买点：** 大盘缩量至6000亿以下+政策底信号
**核心指标：** 两市成交额是最直接的领先指标

### 6. 中芯国际 (688981) — 制裁博弈

**脉冲驱动因素：** 美国制裁升级/国产替代政策/先进制程突破传闻
**典型脉冲模式：** 制裁消息→急跌10-15%→政策对冲→反弹至前高
**最佳买点：** 制裁恐慌性杀跌(往往是过度反应)

## 短线操作纪律

```
铁律（违反任何一条必须反思）:

1. 单票仓位 ≤ 10%（中际旭创/隆基等高波动 ≤ 5%）
2. 止损：破箱底3-5%无条件止损，绝不扛单
3. 止盈：触箱顶先出2/3，剩余1/3看能否突破
4. 不追高：已脉冲启动超过箱体中轴的不追
5. 看量：放量突破箱顶可能开启新箱体；缩量到箱顶必卖
6. 时间止损：买入后5个交易日无启动→平仓换股
7. 大盘环境：上证跌破关键支撑时全部清仓观望
8. 不隔夜重仓：尾盘不确定时减至半仓以下
9. 每日复盘：记录买卖理由，月度统计胜率
10. 亏损上限：单月亏损达本金5%时强制休息一周
```

## 资金分配建议

```
总短线资金 = 可投资资产的 20-30%（其余做长线达尔文策略）

分配方式:
- 同时持有 ≤ 3只（集中精力）
- 每只仓位: 总短线资金的 25-35%
- 保留 30% 现金等待极佳机会
- 每周交易 ≤ 5次（避免过度交易）
```
