# How to Pick a Good Company

基于 Pulak Prasad《What I Learned About Investing from Darwin》(2023)
Pulak Prasad — Nalanda Capital创始人/CEO，管理~$50亿，专注印度上市股权

---

## 核心哲学

投资如进化：**生存第一，最大化第二。**

三大支柱：

1. **避免大风险** — 不亏钱比赚钱重要
2. **以合理价格买高质量公司** — 只买"适者生存"的企业
3. **极度懒惰** — 买入后几乎不动，让复利工作

---

## 支柱一：避免大风险 (Avoid Big Risks)

**"在进化中，致命错误的代价是灭绝。投资亦然。"**

### Type I Error (致命错误) — 必须避免

亏损50%需要赚100%才能回本。一个大亏损可以抹杀多年小收益。

### 排除清单 (Kill List)

以下任何一条触发 → **直接排除，不做进一步分析：**

| # | 排除条件 | 原因 |
|---|----------|------|
| 1 | **不诚信的控制人/管理层** | 骗你一次必骗你第二次，无法修复 |
| 2 | **高负债/杠杆** | 放大下行风险，经济衰退时可致命 |
| 3 | **频繁并购** | 摧毁价值的概率远高于创造价值 |
| 4 | **快速变化的行业** | 今天的赢家明天就可能被颠覆 |
| 5 | **困境反转型** | 大多数困境公司不会反转，只会更困 |
| 6 | **利益不一致** | 管理层/大股东与小股东利益冲突 |
| 7 | **国企/政府控制** | 可能做出非市场化决策，股东利益排后 |
| 8 | **过度依赖单一客户/产品** | 集中风险，一旦失去即崩塌 |
| 9 | **复杂难懂的商业模式** | 你不懂的东西无法正确评估风险 |
| 10 | **历史上有过欺诈/造假** | 文化不会改变 |

### 实操

- 在分析任何公司之前，**先跑排除清单**
- 如果触犯任何一条 → 停止分析，寻找下一个
- 宁可错过好机会，不可买入烂公司

## 支柱二：以合理价格买高质量 (Buy Quality at Fair Price)

**"在投资中，如同在西伯利亚，只有适者生存。"**

### 什么是"高质量"？

衡量一家公司"生存适应度"的核心指标是 **ROCE/ROIC（投入资本回报率）**：

```
ROCE = EBIT / Capital Employed
```

**持续高ROCE意味着同时具备：**

#### 1. 强大的护城河 (Moat)

超额回报未被竞争侵蚀 → 说明存在结构性壁垒

| 护城河类型 | 识别方法 |
|-----------|---------|
| 品牌 | 能否溢价销售？消费者是否非它不可？ |
| 网络效应 | 用户越多价值越大？ |
| 转换成本 | 客户换供应商的代价有多高？ |
| 成本优势 | 规模/流程/地理带来的结构性低成本？ |
| 供给约束 | 产能/牌照/资源无法被复制？ |

#### 2. 优秀的管理层

平庸的管理层无法长期维持高ROCE。检查：
- 资本配置纪律（不乱花钱、不疯狂并购）
- 诚信记录（说到做到，透明披露）
- 长期导向（不为短期业绩牺牲长期价值）
- 股东利益一致（持股、薪酬结构合理）

#### 3. 财务稳健，现金奶牛

- 自由现金流充沛（FCF ≈ 或 > 净利润）
- 低负债或零负债
- 不依赖外部融资即可增长
- 分红+回购体现真实赚钱能力

#### 4. 可持续增长（自我造血）

- 有机增长 > 并购增长
- 再投资空间充足（ROCE高 + 增长跑道长 = 完美复利机器）
- 行业结构支持长期增长

### 不要为质量过度付费

**"即使是最好的公司，买贵了也是差投资。"**

- 不依赖DCF精确估值（"Darwin吃掉了我的DCF"）
- 未来不可预测，不要假装能精确预测10年现金流
- 用**安全边际**替代精确预测
- 关注：PE相对历史、FCF yield、与同行对比
- 在市场恐慌/暂时性困难时买入 → 好公司被市场误杀时才有好价格

### 不要混淆青蛙和孔雀鱼 (Don't Confuse a Green Frog for a Guppy)

- 表面相似 ≠ 本质相同
- 深入研究商业模式、竞争格局、管理层品质
- 不要被表面增速/故事迷惑
- 三角验证：多来源、找反对意见、用检查清单

## 支柱三：极度懒惰 (Be Very Lazy)

**"有时候，最好的投资决策就是什么都不做。"**

### 为什么不动？

| 原因 | 解释 |
|------|------|
| 复利需要时间 | 频繁换股打断复利 |
| 交易成本 | 每次买卖都有摩擦（税、佣金、bid-ask） |
| 行为错误 | 越频繁操作，犯错概率越大 |
| 信息幻觉 | 更多信息 ≠ 更好决策 |

### "间断平衡"投资法 (Punctuated Equilibrium)

来自Eldredge和Gould的进化理论：物种大部分时间保持稳定，偶尔突然演化。

投资也应如此：
- **95%的时间：什么都不做** — 持有高质量公司，忽略噪音
- **5%的时间：果断行动** — 当极端低估/公司基本面断裂时才买入或卖出

### 何时卖出？(极少数情况)

| 卖出条件 | 说明 |
|----------|------|
| 护城河被永久侵蚀 | 竞争格局发生不可逆变化 |
| 管理层诚信出问题 | 一旦欺骗，不给第二次机会 |
| 原始投资逻辑被证伪 | 你看错了，承认并退出 |
| **不因短期业绩波动卖出** | 好公司也有坏年份 |
| **不因股价下跌卖出** | 价格≠价值 |

## 对抗行为偏差 (Don't Be Pavlovian)

**"在投资中，反射性反应是危险的。"**

| 偏差 | 对策 |
|------|------|
| 恐慌卖出 | 预设规则：只在逻辑断裂时卖 |
| 追涨杀跌 | 反向操作：别人恐惧时贪婪 |
| 锚定效应 | 定期重新评估，不锚定买入价 |
| 从众心理 | 独立思考，寻找反对证据 |
| 过度自信 | 写决策日记，事后复盘 |

## 检查清单总结

```
投资决策流程:

[1] 排除清单检查 → 触犯任何一条？→ 放弃
                                    ↓ 通过
[2] ROCE是否持续高于15%？(5年以上) → 否？→ 放弃
                                    ↓ 是
[3] 护城河来源清晰？可持续？        → 不确定？→ 放弃
                                    ↓ 是
[4] 管理层诚信+能力？               → 有疑问？→ 放弃
                                    ↓ 是
[5] 估值合理？(非泡沫价格)          → 太贵？→ 加入观察清单，等待
                                    ↓ 合理
[6] 买入，然后极度懒惰
```

---

## 一句话总结

> **不惜一切代价不买错公司。买入正确的公司后，不惜一切代价不卖出。**
